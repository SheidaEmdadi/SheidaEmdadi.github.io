# Sheida Emdadi — Academic Website

Personal academic website, built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll theme (a fork of [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)).

## Editing this site

- Site-wide info (name, bio, contact links) → `_config.yml`
- Top navigation → `_data/navigation.yml`
- About page → `_pages/about.md`
- Education page → `_pages/education.md`
- Research page → `_pages/research.md`
- Publications → one file per paper in `_publications/`
- Teaching → one file per role in `_teaching/`
- Projects → one file per project in `_portfolio/`
- CV → `_pages/cv.md` (links to the PDF in `files/`)
- Profile photo → `images/profile.jpg` (replace with a real headshot any time; square images work best)

Push changes to the `main` branch and GitHub Pages rebuilds automatically within a minute or two.
