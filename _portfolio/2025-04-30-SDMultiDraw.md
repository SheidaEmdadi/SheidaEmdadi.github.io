A collaborative state diagram editor built in Elm, supporting real-time editing, transition creation, and an Interruption Management System (IMS) for classroom interaction.

The system allows multiple users to edit diagrams simultaneously while preventing conflicts through state reservation and synchronized global updates.

Code: [github.com/FondationSTaBLFoundation/SDMultiDraw](https://github.com/FondationSTaBLFoundation/SDMultiDraw)
